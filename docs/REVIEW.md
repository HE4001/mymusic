# 项目审查记录

## 当前状态

播放器使用共享密码和服务端会话保护曲库、播放地址及媒体跳转。前端直连私有 B2 音频；当前支持系统媒体控件、进度拖动和本地收藏。以下记录按阶段保留，历史的匿名访问说明不代表当前行为。使用与部署以 [README](../README.md) 和 [DEPLOY](DEPLOY.md) 为准。

## 历史记录：2026-09-08 与曲库同步初期

2026-09-08：按用户明确要求移除 Cloudflare Access。曲库和播放地址接口现在无需登录；B2 桶仍为私有，应用密钥仍只在服务端签名使用。

- 删除 Access 验证模块、JWT依赖、ACCESS_TEAM_DOMAIN/ACCESS_AUD配置及前端登录提示。
- 保留白名单歌曲ID、对象路径校验、短期GET签名、统一错误响应和no-store。
- 本地 Pages 运行时实测：不带登录头访问 /api/library 返回200和空曲库JSON，带no-store；随后停止本地验证进程。
- 去掉测试中的鉴权mock，直接验证匿名请求能够访问接口、私钥不出现在响应中，错误不回显敏感信息。
- 类型检查及28项测试通过：19项服务端、6项路由、3项播放流程。
- 曲库校验、Vite构建通过；Functions因Windows沙箱父目录权限受阻后，在批准的沙箱外本地编译通过。
- 保留一项播放竞争消融：22项基线通过，移除旧请求保护后恰好一个对应失败。JWT消融随功能删除，不保留无效检查。

本轮没有读取或设置真实密钥，没有更改Cloudflare平台策略。若平台仍保护播放器域名，需要在那里取消该播放器的Access保护；仓库代码不能解除平台拦截。

当前配置共五项：B2_ENDPOINT、B2_REGION是普通变量；B2_BUCKET、B2_KEY_ID、B2_APPLICATION_KEY是Pages Secrets。浏览器能够看到签名URL里的桶名、对象路径和key ID，应用私钥不发送客户端。持有网址的人可以获取曲库和播放票据。

真实B2读取、Range、票据过期和手机后台播放仍需配置真实环境验收。早期任务书保留为历史分工记录，其中Access要求已被本轮用户指令替代。当前使用说明以README和DEPLOY为准。

曲库同步续作：新增构建前B2 ListObjectsV2同步，复用aws4fetch，XML解析器仅开发依赖。32项测试通过（新增4项覆盖分页/编码、稳定ID/元数据、格式错误、失败与重复分页），普通构建保持离线。未读取真实密钥，未实际列出用户桶；真实同步需Pages提供Secrets、listFiles权限及music/目录。
