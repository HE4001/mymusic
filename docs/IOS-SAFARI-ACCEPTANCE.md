## 当前反馈与修正

用户在 iPhone 16、iOS 27、Safari 直接打开网页时反馈：系统播放小卡片和灵动岛信息完全空白。22af1d2 版本的歌曲信息显示验收失败。后续修正将元数据同步放到原生播放调用前后、playing、loadedmetadata、暂停和页面前后台事件中，不增加保活定时器；修正后的真机结果仍待验证。

## 必测项目

| 项目 | 操作 | 通过条件 | 结果/证据 |
| --- | --- | --- | --- |
| 播放信息 | 播放一首并切换至少一首，查看系统 Now Playing | title、artist、album 与当前曲目一致；不出现签名 URL、密钥或上一首残留 |  |
| 系统控制 | 在锁屏/控制中心执行暂停、继续、下一首 | 每个动作只执行一次；暂停后不被恢复流程误当成播放 |  |
| 后台 5 分钟 | 播放后锁屏或切到其他 App，等待 5 分钟再返回 | 页面未被系统回收时，音频、曲目、进度、播放状态与实际一致；返回不因 `pageshow`/focus 自动误播 |  |
| 锁屏/后台 30 分钟 | 播放队列后锁屏或切后台，等待 30 分钟，期间至少跨过两次切歌 | 记录是否连续、是否切歌、系统信息是否同步；返回后状态一致 |  |
| 断网恢复 | 播放中断网，触发一次页面恢复/手动重试，再恢复网络 | 临时会话失败不卸载已认证播放器；网络恢复后可重新操作；不要求无缓存断网持续出声，不接受高频轮询 |  |
| 电话中断 | 播放中接听/模拟电话或其他系统音频中断，结束后观察 | 不抢播、不把暂停误恢复；用户明确继续时才继续 |  |
| 退出清理 | 播放中点击“退出”，再查看播放器与系统媒体控件 | 音频停止；Now Playing、锁屏信息和可清理的媒体元数据不残留 |  |
| 密码过期 | 在受控环境使现有会话过期/密码轮换，触发一次受保护请求 | 明确失效后回到登录；旧播放器不再可用；输入新密码可重新进入；密码不出现在页面日志或持久化存储 |  |

## 系统显示边界

- Now Playing、锁屏控件和灵动岛是否出现、出现哪些字段及可用动作，均由 iOS/Safari 系统控制；逐项记录“系统显示/未显示”，不要用网页 CSS 代替验证。
- 本清单不承诺自定义 ActivityKit 灵动岛或原生 Live Activity；也不承诺 Safari 页面不被 iOS 回收。若页面被系统回收，记录为外部限制并保留设备、iOS、网络和省电模式证据。

## 结论

- 只有所有必测项目均已在上述真实设备和入口执行、留有结果与证据，才可给出真机验收结论。
- 任一项目为“未测试”时，整体结论只能是“未完成”，不能宣称 iOS 后台播放或灵动岛通过。
