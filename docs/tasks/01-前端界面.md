# A：前端界面（sol xhigh）

## 目标

将设计指南第 2、3 节落实成可用的中文音乐播放器。你只负责界面，用已经约定的 usePlayer 与 API 接线，不能另造音频实例。

## 写入范围

src/App.tsx、src/styles.css、src/components/**。不修改 hooks、lib、types、工程配置。直接在工作区写文件。

## 细项

1. App 加载曲库、取消过时请求，明确 loading/error/empty/搜索无结果，失败可重试；401 或 HTML 登录响应给重新进入入口。
2. 搜索 title/artist/album；全部/收藏标签；列表先显示 100 首、加载更多；点击歌曲传完整筛选快照给 player.selectTrack，不能只传当前渲染页。
3. 深色列表式界面、青绿色强调；左栏、搜索区、当前曲目状态、底部固定播放器；桌面 900px 断点，手机底部迷你栏与完整播放器。
4. 播放/暂停、前后曲、顺序/随机/单曲循环、进度预览并在释放后 commit seek、音量和队列抽屉；收藏独立按钮。
5. 原生 button/input/range，aria-label、可见焦点、44px 触摸区域；弹层使用原生 dialog 或完善焦点/Escape 行为；输入时不触发 Space 全局播放。
6. 状态来自 PlayerController；duration null 显示 --:--；canSeek=false 时禁用进度；错误/提示区域可读。
7. 开发模式由 DEV 与 ?demo=1 双重条件切换，导入 demoLibrary/usePlayer 的 demo 选项；显著标注“演示曲库”，正式接口失败不偷偷展示示例。生产没有演示入口。
8. 手机/桌面共享一个 controller；队列选择保留现有 queue；上一首/下一首策略属于 hook，不在 UI 重新计算。

## 约束与验收

不安装 UI 框架、图像生成或无关导航。不需要封面图片，可用图标/文字占位。CSS 控制最大宽度、长歌名、省略与安全区，底栏不遮末行。让首屏就可以收听，不做宣传页。

完成时报告组件列表、响应式规则、接线状态和接口缺口。不需要截图测试、不跑大规模测试，主代理统一集成并审查。
