# 本轮界面与机密配置（2026-09-08）

## 任务目标

本轮把部署文档统一为以下配置边界：`B2_BUCKET`、`B2_KEY_ID`、`B2_APPLICATION_KEY` 全部使用 Cloudflare Pages Secrets，不写入 Wrangler `vars`；`B2_ENDPOINT`、`B2_REGION`、`ACCESS_TEAM_DOMAIN`、`ACCESS_AUD` 使用普通变量，并分别维护 production 与 preview 值。

浏览器直连 B2 的预签名 URL 必然会带有桶名、object path、key ID 和短期签名/过期参数。`B2_APPLICATION_KEY` 只在服务端签名，不发送到客户端。Pages Secret 保护 Cloudflare 中保存的值，不隐藏浏览器可以看到的请求地址。`.dev.vars` 仅用于本地 Pages Functions 开发，不部署、不提交；本轮不读取真实 `.dev.vars`，只引用占位示例。

保持现有架构：Pages Functions 签发短期 B2 URL，浏览器直接播放 B2；不新增音频代理、数据库、上传后台或其他业务接口。不部署，不索取或传递聊天中的真实密钥。文档代理不跑构建或测试，代码检查与最终构建由主代理和服务端代理完成。

## 核对来源

- [Cloudflare Pages Wrangler 命令](https://developers.cloudflare.com/workers/wrangler/commands/pages/)：`npx wrangler pages secret put [KEY]`、`--project-name` 和 `--env`。
- [Cloudflare Pages Functions Wrangler 配置](https://developers.cloudflare.com/pages/functions/wrangler-configuration/)：顶层配置用于本地/production，`env.preview` 用于 preview；Pages 只支持 production 和 preview 两个环境。
- [Cloudflare Pages bindings](https://developers.cloudflare.com/pages/functions/bindings/)：Pages Secret 通过 `context.env` 使用，本地 Secret 使用 `.dev.vars`，不要把敏感值写入 `vars`。
