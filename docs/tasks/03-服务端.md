# C：B2 与 Access API（sol xhigh）

## 目标与范围

实现 server/**、functions/**、tests/server*.test.ts。不要写其他模块/配置。使用 aws4fetch、jose、Cloudflare PagesFunction 类型。配置来自 context.env，绝不能 VITE_。

## 模块与实现

1. server/library.json 默认有效空库（schemaVersion:1、updatedAt 合法日期、tracks:[]），不要造不存在的 B2 歌曲。可提供 server/library.example.json 含占位对象供手工替换，明确不会被加载。
2. library.ts 导出 validateLibrary(value:unknown)、getLibrary()、findTrack(id)。类型包含 objectKey；id 长度上限且稳定唯一，必填 title/key，允许 artist/album 缺省，duration null 或正有限数，mimeType 合法字符串；限定 music/，拒绝点路径、反斜杠、空段和控制字符。getLibrary 只选择前端字段。
3. b2.ts 按指南签发 GET；允许 B2 s3.<region>.backblazeb2.com https endpoint、检查 region 一致、bucket 合法且无 credentials/port/path/query/hash。逐段编码中文、空格、#?%，Range 不签入，signed host 不改。TTL 默认3600，若提供 B2_URL_TTL_SECONDS 用于测试则校验合理范围（例如60..3600）并在 env 类型说明。
4. access.ts 用 jose jwtVerify + 固定团队域名远程 JWKS，验 issuer/audience/expiry/签名、约束算法，不能信任邮箱 header，不自行实现 JWT；缓存 key set。缺少配置或无效配置默认拒绝，不提供线上 dev bypass。
5. functions/api/_middleware.ts 包装 API：访问验证、异常转换、所有响应 JSON/no-store、禁止泄漏秘密；失败返回稳定 code；未知路由不能意外暴露静态 JSON。
6. GET /api/library 与 GET /api/play-url 仅接收文档输入；play-url 验单个 id，拒绝未知字段/重复id/任意URL/对象key；unknown id 404；不支持 method 405 Allow GET。鉴权失败401、配置错误500，客户端可读中文消息，不返回内部异常堆栈。
7. 签名只生成 URL，不 HEAD B2、不代理音频、不列桶、不联网自动扫描。

## 有限测试

几个风险用例即可：无 JWT 拒绝且 next 未调用、配置失败关闭、清单未知 id、特殊文件名签名路径 roundtrip、危险 key 拒绝、安全字段映射。可以用本地生成测试 JWT/固定 JWKS 验自己的校验接线，不做网络集成或重测 jose 全库。主代理统一执行测试。
